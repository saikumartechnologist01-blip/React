Template Literals: 

It allows the developer to write multiple lines in a string in a free-style. 

To use template literals, we need to use backtik (``)

syntax:  var template = `


`

Before ES6:

var template= "Hello User,  \n\t\t\t Your Subscription is about to end. please renew it before 2nd Feb. \n \t Thanks, \n Product Team";
console.log(template); 

With ES6:

var template= `Hello User, 
 
      
              Your Subscription is about to end. please renew it before 2nd Feb.
  

  Thanks, 
  Product Team`;
console.log(template);

Rest Parameter and Spread Operator: 



Rest Parameter:  It helps in capturing the additional arguments passed into a function 
as an array. 

ES5: 



 function f1(a,b){
   console.log(a);
   console.log(b);

   console.log(arguments[2]);
   console.log(arguments[3]);
 }

 f1(10,20,30,40);


 ES6: 

  function f1(a,b,...additionalValues){
   console.log(a);
   console.log(b);
   console.log(additionalValues);
 }

 f1(10,20,30,40);


Rest params with arrow functions: 

var f1= (a,b,...additionalValues) =>{
   console.log(a);
   console.log(b);
   console.log(additionalValues);
 }

 f1(10,20,30,40);


 Rest params with array destructuring:

 

var array =[10,20,30,40,50]

const [firstValue,...remainingValues] =array; 

console.log(firstValue);

console.log(remainingValues)


Spread Operator: 

ES5: 

 function f1(a,b,c){

   console.log(a);
   console.log(b); // ? 
   console.log(c);

 }

 var arr=[10,20,30];

 f1(arr[0],arr[1],arr[2]);

ES6:  

 function f1(a,b,c){

   console.log(a);
   console.log(b); // ? 
   console.log(c);

 }

 var arr=[10,20,30];

 f1(...arr); // spread operator

Reduce: 

Reduces the array to a single value. 


const overallBalance = [12000,78788,645656,76767,65656,4545]; 

// ES5

  var sum = 0; 

  for(var i=0; i<overallBalance.length; i++){
        sum += overallBalance[i];
  }
  console.log(sum);

  // ES6

var finalBalance = overallBalance.reduce((acm,value) => acm + value,0);

console.log(finalBalance);
